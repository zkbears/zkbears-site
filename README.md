# ZKBEARS — collection website

A static, responsive introduction and whitelist checklist for a planned collection of 3,333 pixel bears in the Zcash ecosystem.

The homepage contains the collection story, supply, twelve numbered artwork slots, links to X tasks, and a Noir Wallet Unified Address field. X task completion is self-confirmed until X OAuth/API verification is connected. Whitelist progress is stored only in the visitor's browser. Terms open instantly in an on-page dialog, with a separate direct-link page retained as a fallback.

Serve `dist/` with any static server. For local development, run `node preview.mjs`.
